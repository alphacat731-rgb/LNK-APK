🔗 LNK-APK

Turn a website into a clean fullscreen Android app. No browser/search bar. No Cloudflare. ❤️

1. Add your icon (optional)

In your GitHub repo, upload a PNG/JPG into assets/. For example: assets/icon.png.

2. Open the APK builder

GitHub will ask for the app name, website URL, and optional icon path.

OPEN APK BUILDER
3. Run the workflow
  1. Tap Run workflow.
  2. Enter your app name.
  3. Enter the full website URL, including https://.
  4. For your uploaded icon, enter its path, e.g. assets/icon.png.
  5. Tap Run workflow.
When the build finishes, open the completed workflow and download the APK from its Artifacts section.
